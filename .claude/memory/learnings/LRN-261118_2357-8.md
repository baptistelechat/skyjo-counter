# LRN-261118_2357-8 — ImageCapture.takePhoto() : photo délavée vs appareil natif

**Pattern observé** : sur Android (Chrome, Xiaomi), une photo prise par `new ImageCapture(track).takePhoto()` depuis un flux `getUserMedia` n'a pas le traitement d'image de l'appareil photo natif : saturation médiane 0,13 contre 0,25 pour la même scène prise via `<input capture>`. Toute logique fondée sur les couleurs (classification, détection de pixels vifs) se dégrade.

**Contexte** : viseur maison avec cadre rouge/vert, abandonné.

**Application future** : pour une photo dont les couleurs comptent, préférer `<input type="file" capture="environment">` ; si un flux live est indispensable, mesurer la saturation des photos obtenues sur l'appareil réel avant de calibrer des seuils.
