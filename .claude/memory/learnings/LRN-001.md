# LRN-001 — Épingler le moteur Cactus sur la version qui a produit les fixtures (4.1.4)

**Pattern observé** : Le PRD annonçait Cactus v4.1.3, mais les JSON de référence du POC ont été produits par le moteur 4.1.4 embarqué par `cactus-compute` 4.2.6. C'est la version du moteur, pas celle du paquet Python, qui doit être alignée.

**Contexte** : Récupération des assets `cactus.js` + `cactus.wasm` (E1-S2) depuis Hugging Face `Cactus-Compute/cactus/releases/4.1.4/wasm`.

**Application future** : Toute comparaison avec `tests/fixtures/*.mirage.json` doit tourner sur le même moteur que celui qui les a générés ; en cas de montée de version, régénérer les fixtures via `docs/poc/test_mirage_skyjo.py`.
