# BLK-261119_2132-2 — pnpm test chaîné derrière lint/build : 40 min sans sortie

**Friction** : `rtk pnpm lint; rtk pnpm build; rtk pnpm test` dans une même commande Bash, passée en arrière-plan au bout de 120 s : vitest n'a rien affiché pendant 40 min, la sortie restait celle du build.

**Cause réelle** : non élucidée. `rtk` bufferise la sortie jusqu'à la fin, et vitest signale « Timeout terminating forks worker » sur `tests/banc.test.ts` à l'arrêt : le processus a pu ne jamais rendre la main sous `rtk`. Un autre vitest (autre session) tournait en même temps.

**Solution** : lancer vitest seul, en arrière-plan, borné : `timeout 900 npx vitest run --reporter=dot`. Terminé en 45 s, 52/52, code de sortie 0.
