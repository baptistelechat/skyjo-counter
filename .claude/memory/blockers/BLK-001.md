# BLK-001 — Build cassé : `App.tsx` du template importait des assets supprimés

**Friction** : `pnpm build` échouait en `UNRESOLVED_IMPORT` sur `./assets/hero.png`, `./assets/react.svg`, `./assets/vite.svg` et `./App.css`, alors que le lint passait.

**Cause réelle** : Les assets du template Vite avaient été supprimés au nettoyage du scaffold, mais `src/App.tsx` était resté le composant de démo qui les importait.

**Solution** : Remplacer `src/App.tsx` par un écran minimal « Skyjo Scan » sans import d'asset (ancien fichier sauvegardé hors repo).
