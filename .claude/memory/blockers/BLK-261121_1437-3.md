# BLK-261121_1437-3 — Dossier worktree epic-5 impossible à supprimer

**Friction** : après fusion de l'épic 5, `git worktree remove .claude/worktrees/epic-5` a désenregistré le worktree mais laissé le dossier ; `Remove-Item -Recurse -Force` échoue avec « Access denied » sur 4 binaires (`rolldown-binding…node`, `tailwindcss-oxide…node`, `lightningcss…node`, `tsc.exe`). Droits (contrôle total) et attributs (pas de lecture seule) étaient normaux.

**Cause réelle** : pnpm installe par liens physiques depuis son store. Ces 4 fichiers sont le même fichier physique que ceux du `node_modules` principal de skyjo (`fsutil hardlink list`), chargés en mémoire par les serveurs de dev et les `tsc.exe` encore lancés dans le dossier principal. Windows refuse de supprimer tout lien d'une image chargée.

**Solution** : arrêter les serveurs de dev de skyjo (Ctrl+C), puis `Remove-Item -Recurse -Force .claude\worktrees`. Sinon, attendre un redémarrage (~60 Mo, git déjà propre). Voir aussi GLRN-318.
