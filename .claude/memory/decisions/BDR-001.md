# BDR-001 — Inférence Mirage 100 % client via Cactus WASM en Web Worker

**Décision** : Exécuter le modèle Mirage dans le navigateur via le build WebAssembly de Cactus Compute, dans un Web Worker ; Vercel ne sert que des fichiers statiques.

**Pourquoi** : Objectifs du PRD — hors ligne en mode avion après la première visite, hébergement gratuit sans serveur ni API payante, licence Apache 2.0 redistribuable. Le Worker évite de bloquer l'UI pendant l'inférence.

**Alternatives considérées** : API d'inférence côté serveur ou payante — écartée (coût, pas de hors ligne, demanderait un backend hors périmètre).
