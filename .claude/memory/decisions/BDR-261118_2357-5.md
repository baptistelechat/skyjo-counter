# BDR-261118_2357-5 — Fixtures réelles : photos et JSON committés

**Décision** : la page `/?debug` a un bouton « Enregistrer comme fixture » (dev uniquement, middleware Vite dans `vite.config.ts`) qui écrit `tests/fixtures/reel-<score>-<id>.{jpg,wasm.json,meta.json}` depuis le téléphone. Photos et JSON sont committés (le 19/11, Baptiste a choisi de versionner aussi les photos ; elles étaient d'abord gardées en local) : `wasm.json` = sortie Mirage, `meta.json` = score attendu, rotation, recadrage et dimensions `image` analysées. Les tests Vitest (forme de grille, règles de lecture) passent sur tout poste, et les boutons d'analyse réelle aussi puisque les photos suivent le repo. La page liste en boutons les fixtures dont la photo est présente localement, avec une analyse réelle (Mirage complet) par bouton.

**Pourquoi** : chaque photo réelle a révélé un cas inédit ; il faut pouvoir les rejouer. Le rejeu groupé a été retiré : sur les JSON seuls il était trompeur, sur les photos (12 scans d'affilée) trop long.

**Alternatives considérées** : photos en local et JSON seuls committés (première version : tests possibles partout, mais analyse réelle impossible sur un autre poste) ; ne rien committer (tests impossibles ailleurs).
