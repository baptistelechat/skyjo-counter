# BDR-261118_2357-5 — Fixtures réelles : photos locales, JSON committés

**Décision** : la page `/?debug` a un bouton « Enregistrer comme fixture » (dev uniquement, middleware Vite dans `vite.config.ts`) qui écrit `tests/fixtures/reel-<score>-<id>.{jpg,wasm.json,meta.json}` depuis le téléphone. Les photos restent hors commit (non suivies, choix de Baptiste). Les JSON sont committés : `wasm.json` = sortie Mirage, `meta.json` = score attendu, rotation, recadrage et dimensions `image` analysées. Les tests Vitest (forme de grille, règles de lecture) passent donc sur tout poste. La page liste en boutons les fixtures dont la photo est présente localement, avec une analyse réelle (Mirage complet) par bouton.

**Pourquoi** : chaque photo réelle a révélé un cas inédit ; il faut pouvoir les rejouer sans publier de photos personnelles. Le rejeu groupé a été retiré : sur les JSON seuls il était trompeur, sur les photos (12 scans d'affilée) trop long.

**Alternatives considérées** : tout committer (photos personnelles dans le repo) ; ne rien committer (tests impossibles ailleurs).
