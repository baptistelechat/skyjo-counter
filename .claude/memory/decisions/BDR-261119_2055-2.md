# BDR-261119_2055-2 — Confiance par carte : plancher 0,6 si cohérente avec la couleur

**Décision** : chaque carte porte `confiance` (0-1) et `alertes` (`lireCarte` dans `src/lib/skyjo/lecture.ts`, `valider` dans `validation.ts`). Une carte est « à vérifier » sous 0,5 ou avec une alerte : valeur hors couleur, plus d'exemplaires que dans le paquet, colonne presque défaussée. Une lecture directe (sans +10, signe ajouté ni 6↔9), sans désaccord, dont la valeur appartient à la couleur détectée vaut au moins `PLANCHER_COULEUR = 0,6`. Le plancher s'applique avant les malus case estimée (×0,8) et relue (×0,9).

**Pourquoi** : l'OCR de Mirage note ses chiffres justes 0,3 à 0,5, si bien qu'une carte juste lue une seule fois tombait sous le seuil. Mesuré sur les 87 cartes visibles des 12 fixtures : fausses alertes 10 → 4, aucune erreur de plus laissée passer. Les 3 erreurs non signalées (`reel-61-mwmoejrg`, colonne 3) viennent d'un décalage de colonnes de `grilleDeBoites` : la confiance ne peut pas les voir, c'est un problème de détection.

**Alternatives considérées** : baisser le seuil global (ne sépare pas mieux : les erreurs sont à 0,59-0,76) ; ne rien changer (trop de fausses alertes, Baptiste voyait souvent une carte juste à 47 %).
