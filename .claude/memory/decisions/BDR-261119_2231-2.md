# BDR-261119_2231-2 — Partie : grilles saisies par joueur, score figé à la validation

**Décision** : `src/store/partie.ts` (Zustand `persist` sur `idb-keyval`) garde la `partie` (joueurs, `manches: number[][]`) et la `manche` en cours : une `GrilleSaisie | null` par joueur (`CaseSaisie = { valeur, dos, doutes? }`). Le score d'une manche est calculé par `scoreGrille()` et figé à `validerManche()`, possible seulement quand toutes les grilles sont saisies. Une carte non lue reste « à saisir » (`valeur: null, dos: false`, comptée 0). La saisie manuelle part de `grilleVide()` (3×4 à saisir) ; le nombre de colonnes est réglable, car une colonne défaussée quitte la table pendant la manche. Logique pure dans `src/lib/partie.ts`, testée dans `tests/partie.test.ts`.

**Pourquoi** : garder les grilles (pas seulement les totaux) pendant la manche permet de corriger après coup et, plus tard, de collecter des grilles vérifiées pour l'option C ([BDR-261119_2231-1](BDR-261119_2231-1.md)). Figer le total à la validation garde le tableau simple et stable.

**Alternatives considérées** : ne stocker que le score par joueur (plus de correction possible) ; garder les grilles de toutes les manches (inutile pour le MVP, à reconsidérer pour la collecte de données) ; historique de plusieurs parties (hors MVP).
