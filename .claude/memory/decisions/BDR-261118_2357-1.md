# BDR-261118_2357-1 — Cartes choisies par leur forme 2:3, pas par leur nom Mirage

**Décision** : `boitesCartes(m, ratio)` retient les rectangles de forme carte (largeur/hauteur en pixels 0,4-1,15 debout, 1,2-2,5 couchée, l'orientation majoritaire gagne), sans boîtes imbriquées, sans doublons exacts, sans morceaux (< 30 % de l'aire médiane). `ratio` = largeur/hauteur de l'image analysée (les bbox Mirage sont en 0-1000 sur les deux axes).

**Pourquoi** : Mirage nomme les cartes au hasard selon la photo (« patch », « game tile », « sticky note », « cutout », « sticker », « tile ») et mélange parfois plusieurs noms dans une même image (« tile » + « letter », avec « number » pour les coins chiffrés). Garder « la catégorie la plus fréquente » a pris les coins chiffrés pour des cartes et fait perdre une ligne entière (reel-61-mwmozhev).

**Alternatives considérées** : catégorie la plus fréquente (logique du PRD, cassée dès qu'il y a plusieurs noms) ; liste blanche de noms (fragile, Mirage invente). Médiane plutôt que 3e quartile pour le filtre de taille : avec la perspective, les cartes du fond font 1/3 de celles du premier plan (grille-21).
